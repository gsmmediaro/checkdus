# Public Assets Directory

## Salon Storefront Image

To display the salon storefront image on the homepage:

1. Rename your image file `WhatsApp-Image-2025-11-14-at-21.53.19.jpeg` to `salon-storefront.jpg`
2. Place it in this `/public/` directory
3. The image will automatically appear on the home page

**Image Requirements:**
- File name: `salon-storefront.jpg`
- Location: `/public/salon-storefront.jpg`
- Recommended size: 1200x600 pixels (or similar aspect ratio)
- Format: JPG or JPEG

Once added, the image will be displayed prominently on the homepage with the salon information.
